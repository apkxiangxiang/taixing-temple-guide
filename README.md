# 跟志永哥逛泰興宮

台中東勢慶東泰興宮的手機導覽網站，有兩種模式：

- **遠端導覽**（`remote/`）：不在廟裡也能逛。照片、環景、問答、集章，由虛擬志永哥一站一站講解。
  改編自 [TempleGo](https://github.com/Pang-Yiyi/TempleGo)。
- **現場 AR**（`ar/`）：人在廟裡，用手機相機掃描匾額、木牌、彩繪，志永哥會出現在旁邊開口介紹。
  使用 [MindAR](https://github.com/hiukim/mind-ar-js) 與 [three.js](https://threejs.org/)。

志永哥的講話影片放在 `shared/clips/`（透明背景 WebM），兩種模式共用。

志永哥的影像與聲音經本人同意使用。照片來源與授權列在各模式的「資料來源」。
